APRESENTACAO - CONSULTAS REAIS NO MYSQL LOCAL

NOVO: INSERT, SELECT, UPDATE E DELETE DIRETAMENTE NO BANCO
1. Execute npm run demo:up se o ambiente estiver parado.
2. Execute npm run demo:mysql no terminal integrado do VS Code.
3. Abra database/demonstracao_crud.sql e cole UM BLOCO POR VEZ no prompt mysql>.
4. No INSERT, anote o ID mostrado. COMMIT confirma a gravacao.
5. Digite exit; e conecte novamente com npm run demo:mysql.
6. No passo 3 do SQL, substitua o zero pelo ID anotado. O SELECT mostrara o
   registro salvo mesmo apos fechar a primeira conexao.
7. Mostre UPDATE, DELETE com ROLLBACK e depois DELETE com COMMIT.
   O roteiro altera/exclui somente o hotel ficticio criado nessa demonstracao.
8. Ao terminar, digite exit; para voltar ao PowerShell.

As consultas abaixo continuam servindo para os dados gerados pelo REST Client:

1. No terminal do VS Code, na raiz do projeto:
   npm run demo:up

2. Abra meus-testes.http e clique Send Request na ordem numerada.
   O REST Client chama a API; a API grava no MySQL real.

3. Para mostrar as consultas, abra database/apresentacao.sql.
   Para executar todas no terminal, com resultados em tabelas:
   npm run demo:sql

4. Pelo menu: Terminal > Run Task > Apresentacao: Consultar banco (SQL real).
   Execute novamente depois de cada etapa HTTP para mostrar o antes/depois.

5. Para executar uma consulta por vez no cliente MySQL interativo:
   docker compose --env-file .env.docker exec db mysql -u hospedja_app -p hospedja
   Digite a DB_PASSWORD de .env.docker quando solicitado (nao aparece na tela).
   Se DB_USER foi personalizado, substitua hospedja_app pelo valor configurado.
   Cole primeiro: SET @email = 'apresentacao-01@example.test';
   Depois cole o SELECT desejado de database/apresentacao.sql, incluindo ;
   Digite exit para sair.

IMPORTANTE
- REST Client executa HTTP, nao SQL. O terminal MySQL mostra SQL diretamente.
- Nova rodada: altere @rodada em meus-testes.http e @email no SQL para corresponder.
- Reserva criada e um rascunho PENDENTE, sem itens e total zero. LEFT JOIN mostra isso.
- Nao promover usuarios via UPDATE para demonstrar RBAC: os passos HTTP mostram 401/403/422.
- Senhas de demonstracao sao ficticias e exclusivas do ambiente local.
- Nunca executar seed ou este roteiro de escrita no RDS de producao.
- Manual completo: docs/APRESENTACAO_BANCO_REST_CLIENT.md.
